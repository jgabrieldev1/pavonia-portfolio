# Pavonia Audiovisual

Landing page da Pavonia Audiovisual: o filme do set preso atrás da página, uma folha rosada com furos que o revelam, intro com coluna de quadros e o logo animado.

- No ar: https://jgabrieldev1.github.io/pavonia-portfolio/
- Stack: Vite sem framework, Lenis, Geist.

```bash
npm install
npm run dev     # http://localhost:5173
npm run build   # gera dist/
```

Cada push na `main` publica no GitHub Pages (`.github/workflows/pages.yml`).

Primeira versão: o vídeo do fundo, as fotos dos filmes e as miniaturas da intro ainda são provisórios, e os textos entre colchetes esperam os dados da Pavonia. Guia do projeto em `CLAUDE.md`.
